Overview

The Student Grade Tracker is a Java GUI application developed using Swing. It helps users manage student academic records and automatically calculate grades based on marks.

Features
Add Student Records
Update Existing Records
Delete Student Records
Search Student by ID
Automatic Grade Calculation
Display Records in JTable
Generate Summary Reports
Save Data to File
Attractive GUI with Background Image
Technologies Used
Java
Swing
JTable
ArrayList
File Handling
Grade System
Marks	Grade
90+	A+
80-89	A
70-79	B
60-69	C
50-59	D
Below 50	F
How to Run
javac StudentGradeTracker.java
java StudentGradeTracker
